# Rest Clients

Faida Trade API conforms to the Swagger spec for REST endpoints. Any Swagger-compatible client can connect to the Faida Trade API and execute commands.

You can find the swagger spec json for Faida Trade Api [here]
(https://docs.faida.trade/api/swagger_v2.json)

We also have Rest Api Clients available for the following languages

- [Nodejs](https://www.npmjs.com/package/delta-rest-client)
- [Python](https://pypi.org/project/delta-rest-client)
